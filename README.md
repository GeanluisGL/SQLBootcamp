Repositorio con todo el aprendizaje, prácticas y scripts desarrollados durante el **SQL Bootcamp (30 horas) "Go from Zero to Hero"**.

Aquí encontrarás desde consultas básicas hasta temas avanzados como funciones de ventana, CTEs, joins complejos y más. Todo el contenido está organizado por secciones para facilitar su estudio y consulta.

---

## 📚 Contenido del Repositorio

| Sección | Tema | Descripción |
|---------|------|-------------|
| **Section 2** | Select Query | Consultas básicas con `SELECT`, columnas, alias y ordenamiento |
| **Section 3** | Data Definition (DDL) | Creación y modificación de estructuras: `CREATE`, `ALTER`, `DROP` |
| **Section 4** | Data Manipulation (DML) | Inserción, actualización y eliminación de datos: `INSERT`, `UPDATE`, `DELETE` |
| **Section 5** | Filtering Data | Filtrado con `WHERE`, operadores lógicos y `LIKE` |
| **Section 6** | SQL Joins | `INNER`, `LEFT`, `RIGHT`, `FULL` joins y ejemplos multi-join |
| **Section 7** | Set Operators | `UNION`, `INTERSECT`, `EXCEPT` para combinar resultados |
| **Section 8** | String Functions | Manipulación de cadenas: `SUBSTRING`, `CONCAT`, `TRIM`, etc. |
| **Section 9** | Date & Time Functions | Manejo de fechas y timestamps |
| **Section 10** | Null Functions | Funciones para tratar valores nulos: `COALESCE`, `ISNULL`, `NULLIF` |
| **Section 11** | Case When Statement | Lógica condicional con `CASE WHEN` |
| **Oracle.sql** | Script Oracle | Script complementario con sintaxis específica de Oracle |

## 🎯 Objetivos del Bootcamp

- Dominar las consultas SQL desde lo más básico hasta lo avanzado.
- Comprender la manipulación de datos y estructuras (DML y DDL).
- Aplicar joins, subconsultas y operadores de conjunto.
- Manejar funciones de cadena, fecha y valores nulos.
- Escribir consultas condicionales con `CASE WHEN`.
- Adquirir buenas prácticas de organización y documentación de scripts.
